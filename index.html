Pipeline Implementasi

Pindahkan kartu antar-tahapan dengan drag-and-drop, atau ubah status melalui menu edit.

Klik salah satu template untuk membuka isinya. Placeholder @ akan diganti otomatis dengan nama fasilitas yang dipilih. Gunakan tombol Salin Surat untuk menyalin ke clipboard, atau Kirim Surat untuk salin & cetak menjadi PDF.

Komposisi Surat

Pilih template dan fasilitas penerima, lalu salin suratnya atau cetak menjadi PDF untuk dikirimkan ke mitra.

Placeholder @ diganti dengan nama fasilitas terpilih.
Pada dialog cetak, pilih Save as PDF sebagai tujuan printer. Berkas PDF siap dikirim ke mitra melalui WhatsApp atau email.

Pengaturan Data Lokal

Data disimpan pada localStorage browser/perangkat yang sedang digunakan.

Tidak ada server atau akun yang digunakan. Data tidak otomatis tersinkron ke perangkat lain. Gunakan Export JSON sebagai cadangan berkala.

Reset Seluruh Data

Menghapus seluruh fasilitas yang tersimpan di browser ini dan mengembalikan aplikasi ke kondisi kosong. Tindakan ini tidak dapat dibatalkan. Export data terlebih dahulu jika masih diperlukan.

Tahapan Pipeline

Urutan tahapan pada board Kanban. Tambah, edit, hapus, atau geser posisi tahapan (panah naik/turun) sesuai kebutuhan tim.

Template Surat / Pesan Kustom

Buat template surat atau pesan sendiri. Tampil sebagai accordion di menu Template Surat, tersedia juga di menu Kirim Surat, dan ikut terexport dalam cadangan JSON. Placeholder @ diganti nama fasilitas.
