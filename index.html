Pipeline Implementasi

Pindahkan kartu antar-tahapan dengan drag-and-drop, atau ubah status melalui menu edit.

Template dapat disalin dan disesuaikan. Placeholder @ akan diganti otomatis dengan nama fasilitas yang dipilih, misalnya Labkesda Ketapang, RS Sejahtera, Puskesmas Sukamaju, atau Klinik Sehat.

Pengaturan Data Lokal

Data disimpan pada localStorage browser/perangkat yang sedang digunakan.

Tidak ada server atau akun yang digunakan. Data tidak otomatis tersinkron ke perangkat lain. Gunakan Export JSON sebagai cadangan berkala.

Reset Seluruh Data

Menghapus seluruh fasilitas yang tersimpan di browser ini dan mengembalikan aplikasi ke kondisi kosong. Tindakan ini tidak dapat dibatalkan. Export data terlebih dahulu jika masih diperlukan.

Tahapan Pipeline
